# LinkedIn Lab for Project Managers — Target Connect Pathway

Source deck: `LinkedIn_Workshop_L4_PRM.pptx` (Level 4 Project Management workshop)

This repo contains the workshop content split into 9 individual Pathway pages,
ready to build out in Target Connect.

## Structure

Each page is organized as:
- `page-X-content.html` — the main HTML content to paste into Target Connect's Content/HTML block
- `page-X-activity.md` — the task/activity to add as a separate Task/Activity block

4. **Why LinkedIn Matters for Jobseekers** — embedded video
5. **Access LinkedIn** — account setup
6. **Creating Your Profile** — profile picture, headline, About section
7. **Your About Section** — professional storytelling
8. **Add Your Experience, Projects and More** — portfolio building
9. **Your First Connections & Ongoing Project** — networking and next steps

## Building the Pathway in Target Connect

Target Connect doesn't support importing files directly into a Pathway —
Pathways are built page-by-page in the Pathway editor. To build this one:

1. In Target Connect admin, go to **Pathways → Create Pathway** and name it
   *"LinkedIn Lab for Project Managers"*.
2. For each page (1–9):
   - Add a new Pathway page, using the title from the filename or activity file.
   - Add a **Content/HTML block**, open its source/HTML view (usually a
     `<>` icon in the rich-text toolbar), and copy the entire contents of
     `page-X-content.html` into it.
   - Add a separate **Task/Activity block** below the content, using the task type
     and description from `page-X-activity.md`.
   - Replace any `[IMAGE PLACEHOLDER]` or `[EMBED]` notes with your own
     images, screenshots, or video embeds (detailed in each activity file).
3. Set the pages to run in sequence, and set completion criteria per your
   institution's usual Pathway settings.
4. Preview the Pathway end-to-end before publishing to students.
